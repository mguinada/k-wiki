k-wiki software system

An LLM-maintained knowledge wiki built as derived data from a human-owned Obsidian vault. Deterministic sync projects the vault into an immutable raw/ tree; prompted agent runs turn it into a structured, interlinked wiki/; both are versioned in a git data repo.

  • Two agent contexts, never mixed: wiki operations (minimal, traceable edits) vs pipeline development (free refactoring).
  • Core rule: the vault is the source of truth; raw/ and wiki/ are disposable and regenerable.
